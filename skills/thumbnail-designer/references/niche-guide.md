# Niche Visual Vocabulary (decision aid, not template)

Pick from real topic. Unknown niche → analyze independently.

| Niche | Use | Avoid |
|---|---|---|
| Finance/investing | charts (generic, unlabeled as real), currency, banking, assets; navy/charcoal/white + restrained gold. Loss topics → emphasize risk/downside | fake prices, returns, balances, charts presented as real data |
| Real estate | actual property photo if given, exteriors, skyline, comparison, floor plan; blue/white/neutral/warm | inventing features; passing illustration as user's property |
| Fitness/anatomy/health ed | equipment, movement, accurate anatomy of the relevant part, clean athletic/medical graphics | random muscles/organs/symbols |
| Tech/AI/software | devices, UI, dashboards, abstract digital, restrained neon, clean futuristic type | invented UI features; fake screenshots as real results |
| Business/productivity | offices, workflows, revenue diagrams, pro portraits, editorial layout | generic luxury symbols |
| Education/tutorial | the actual tool/concept, screenshots, numbered steps, before/after, labels | drama over comprehension |
| News/politics | relevant people/locations, verified docs, maps, restrained type | fabricated quotes/events/evidence; edits showing someone doing what they didn't |
| Documentary/mystery/history | locations, artifacts, maps, plausible dramatic light, clues | passing recreations as authentic archive |
| Gaming/entertainment | requested characters/gameplay, action composition, high-contrast type | swapping in unrelated generic art |
| E-commerce/review | actual product, details, callouts, comparisons, clean bg | invented specs/performance claims; altering product shape/branding |
| Food/travel/lifestyle | the actual dish/place/activity, natural color, readable text | over-saturation that misrepresents reality |

## Palette by intent
Trust: navy/blue/white · Luxury: black/charcoal/warm neutral/gold · Urgency: controlled red/orange · Nature: greens/earth · Tech: cool blue/cyan · Medical: clean white/restrained blue · Emotional: colors matching real mood.

## Style menu
Premium cinematic · minimalist · high-contrast YouTube · luxury editorial · corporate · documentary · investigative · finance · real estate · fitness · tech/AI · gaming · educational · news · product · before/after · storytelling · clean infographic. Don't reuse one template for everything.
