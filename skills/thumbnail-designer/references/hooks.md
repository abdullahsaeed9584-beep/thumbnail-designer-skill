# Headline Hooks

Thumbnail text is not a summary. It is the **second half of a question the title started** — or the half the title left out.

## Rules
- 2-4 words (5 max). Shorter always wins at 168 px.
- Never duplicate the title. If the title says it, the thumbnail shows it.
- One highlighted keyword — the emotional or numeric payload.
- Honest: every promise must be in the video. Uppercase is fine; lying is not.
- Numbers beat adjectives. `$0 TO $10K` > `HUGE GROWTH`.
- "No text" is a valid, often premium choice when the image carries the idea alone.

## Formulas that work
| Pattern | Shape | Example |
|---|---|---|
| Stakes | finality / consequence | `IT'S OVER` · `TOO LATE` · `GAME OVER` |
| Transformation | from → to | `$0 TO $10K` · `0 TO 100K` · `BROKE → RICH` |
| Error | the mistake | `BIG MISTAKE` · `STOP DOING THIS` · `WRONG WAY` |
| Secret | withheld info | `NOBODY TELLS YOU` · `THE REAL REASON` · `HIDDEN FEE` |
| Number | quantified payoff | `3 RULES` · `7 DAYS` · `90% FAIL` |
| Contrast | A vs B | `CHEAP vs PRO` · `BEFORE / AFTER` |
| Question | open loop | `WHY?` · `WHO PAYS?` · `NOW WHAT?` |
| Warning | risk flag | `DON'T BUY` · `READ FIRST` · `RISKY` |
| Proof | result shown | `IT WORKED` · `DAY 30` · `REAL RESULT` |
| Identity | reader-targeted | `IF YOU'RE 25` · `BEGINNERS ONLY` |

## Pairing with the title
| Title does | Thumbnail should |
|---|---|
| States the topic | Supply the emotion or stakes |
| Asks a question | Show the consequence, not the answer |
| Gives a number | Show the single most surprising item |
| Names a person/product | Show the reaction or the result |
| Already short + punchy | Use 0-2 words, or none — let the image carry it |

## Banned
Fabricated figures, fake quotes, invented prices, "SHOCKING" with nothing shocking, a result the video never shows, arrows pointing at nothing, `#1 BEST` claims you can't support, and anything that makes the viewer feel tricked after 30 seconds. Retention beats clicks.

## Urdu / Roman Urdu
Keep the user's register. Roman Urdu stays Roman Urdu (`PAISA KAHAN JATA HAI`). Nastaliq script needs fewer words still — 2-3 max — and more line-height; see `composition-type.md` §Urdu.
